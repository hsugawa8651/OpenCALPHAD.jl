# OpenCALPHAD.jl Examples

Last-Modified: 2026-05-07

## Numbering System

| Range | Category | Description |
|-------|----------|-------------|
| 000 | Documentation | This index file |
| 1xx | Basic Calculations | Gibbs energy, chemical potential |
| 2xx | Equilibrium | Miscibility gap, two-phase equilibrium |
| 3xx | STEP / MAP | Temperature/composition sweeps |
| 4xx | Phase Diagrams | Complete phase diagrams |
| 5xx | Simulation Coupling | Driving force, diffusion potential |
| 6xx | Advanced | Magnetic contribution, parameter optimization |
| 9xx | Benchmarks | Validation against openCALPHAD (Fortran) |

**Material System Codes** (2nd digit):
| Code | System | TDB File |
|------|--------|----------|
| x1 | Ag-Cu | agcu.TDB |
| x2 | Cr-Mo / Cr-Fe | steel1.TDB (via component_indices) |
| x3 | Fe-Ni | FENI_clean.TDB (magnetic) |

If `z = 0..9` fills up, extend to `a`, `b`, `c`, ... (base-36 style).

## Suffix Convention (Feature Variants)

Feature variants of a baseline use the **same `xyz` number plus a suffix**;
no new number is allocated. Cross-project convention shared with BoltzTraP.jl,
PhaseFields.jl, and PhoXonic.jl.

| Suffix | Engine | Output | Status |
|--------|--------|--------|--------|
| (none, baseline) | Plots.jl (RecipesBase) | screen / PNG | active |
| `_publication`   | PythonPlot (matplotlib) | static PDF / PNG (papers, posters) | **active** (2026-05) |
| `_makie`         | CairoMakie | static PDF / PNG (alternative aesthetic) | reserved |
| `_animation`     | `Makie.record` (CairoMakie / GLMakie) | mp4 / gif time evolution | reserved |
| `_interaction`   | GLMakie | runtime interactive window | reserved |

`_publication` is **selective**: added only for baselines used in JOSS papers,
conference posters, or documentation figures. Validation scripts (`9xx`) are
excluded — they remain numerical-only.

The PDF / PNG files generated by `_publication` scripts are gitignored
(`*_publication_*.pdf`, `*_publication_*.png`); only the script itself is
tracked. Run the script locally to regenerate the figures on demand.

## How to Run

```bash
# Navigate to the package directory
cd OpenCALPHAD.jl

# Run a single example
julia --project=. examples/101_gibbs_energy_agcu.jl

# Run with plots displayed
julia --project=. -i examples/411_phase_diagram_agcu.jl
```

## Dependencies

All examples use:
- `OpenCALPHAD` (this package)
- `Plots` (for visualization)

Some examples additionally require:
- `ForwardDiff` (for automatic differentiation)
- `Optim` (for parameter optimization)
- `JSON` (for reference data loading)
